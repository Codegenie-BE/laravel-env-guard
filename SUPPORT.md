# Support

## Usage questions

Use [GitHub Discussions](https://github.com/Codegenie-BE/laravel-env-guard/discussions) for installation questions, configuration guidance and Laravel environment edge cases.

Include only what is needed to understand the scenario:

- Laravel Env Guard, PHP and Laravel versions
- operating system
- the relevant environment **key names**
- the smallest safe source snippet that reproduces the behavior
- the finding code/message when applicable

Never post `.env` values, tokens, credentials, private URLs, customer data or other secrets. Replace unavoidable example values with obvious placeholders.

## Bugs and detection reports

Use the structured [issue forms](https://github.com/Codegenie-BE/laravel-env-guard/issues/new/choose) for reproducible bugs, false positives, false negatives and focused feature requests.

A useful detection report contains the smallest safe example that demonstrates the issue without exposing environment values.

## Security

Do not open public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md) and its private reporting guidance.
