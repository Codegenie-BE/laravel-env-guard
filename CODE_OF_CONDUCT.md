# Code of Conduct

Laravel Env Guard is an open-source project intended to support constructive technical collaboration.

## Expected behavior

Participants are expected to:

- communicate respectfully and professionally;
- focus criticism on code, behavior and technical decisions rather than people;
- provide reproducible, relevant context when reporting problems;
- respect privacy and never publish credentials, environment values, customer data or other confidential information;
- accept reasonable moderation intended to keep the project useful and safe.

Harassment, personal attacks, discrimination, threats, deliberate disruption and publication of another person's private information are not acceptable.

## Scope

This code applies to issues, pull requests, GitHub Discussions and other project spaces managed by Codegenie.

## Enforcement

Project maintainers may edit, hide, lock or remove content and may restrict participation when necessary to enforce these expectations.

For conduct concerns that should not be discussed publicly, contact Codegenie through https://www.codegenie.be.
